# ライフゲーム(Conway's Game of Life)

## 学習ポイント
2D配列操作、GUI描画、タイマー駆動更新

## 概要
Conwayのライフゲームを、`javax.swing.Timer`で世代更新しながらグリッドを描画するSwing GUIアプリ。
マス目をクリックして初期パターンを編集し、「開始」「停止」「1世代進める」「クリア」「ランダム生成」ボタンで操作する。

## 実装メモ
- Issue #11/#18/#21と同じ方針で、`Grid`/`GameOfLife`はGUIに依存しない純粋なロジックとしてTDDし、`LifeFrame`は実装後に実機起動・スクリーンショットで手動確認した。
- `Grid`は`boolean[][]`の2次元配列で盤面を表現し、`countLiveNeighbors`は境界外を非生存として扱う(トーラス状のラップアラウンドはしない、盤面の端では隣接マスが少なくカウントされる仕様)。
- `GameOfLife.nextGeneration`は現在の`Grid`を書き換えず新しい`Grid`を返す純粋関数とした。世代更新中に元の盤面を参照しながら判定する必要があるため、インプレース更新だと参照している最中に値が変わってしまう不整合を避けられる。
- ソルバーのテストでは、既知の周期パターン「ブリンカー」(3マスの直線が1世代ごとに90度回転する)を使い、隣接セル数だけでなく実際のパターン変化まで含めて`nextGeneration`の正しさを検証した。
- `LifeFrame`は`javax.swing.Timer`で一定間隔(150ms)ごとに世代を進める「タイマー駆動更新」を実装した。フレームワーク指定のない学習ポイントだったため、既存exercise(#11/#18)と同じSwingを採用し、新規依存関係を増やさずに済ませた。
- 手動確認では、実際にWindows上でアプリを起動し、「ランダム生成」で初期パターンを作成→「開始」でタイマーが自動的に世代を進める(2秒間で13世代)ことをスクリーンショットで確認した。
