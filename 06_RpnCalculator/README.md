# 簡易電卓(逆ポーランド記法)

## 学習ポイント
Stackクラスの活用、パーサー実装

## 概要
逆ポーランド記法(RPN)の数式(例: `3 4 +`)を評価する対話式CLI電卓。数値は`BigDecimal`で厳密に計算する。`exit`で終了する。

## 実装メモ
- `java.util.Stack<BigDecimal>`にトークンを順次push/popすることでRPNを評価する。演算子が来たら直近2つの値をpopして計算し、結果を再度pushする。
- 01_Calculatorと同様、`0.1+0.2`のような誤差を避けるため`double`ではなく`BigDecimal`を使用。除算はスケール10・`RoundingMode.HALF_UP`で丸める。
- パーサーとしての妥当性検証は3種類: ①数値でも演算子でもないトークン、②演算子適用時のオペランド不足、③評価終了時にスタックへ複数(または0個)の値が残る不正な式。いずれも`RpnCalculatorException`にまとめ、`Main`側で一律にエラー表示・継続できるようにした。
- `Main`は01〜05と同じ設計パターンで、Scanner/PrintStreamを引数に取る`run`静的メソッドに分離し、不正な式でクラッシュせず継続することを結合テストで検証した。
