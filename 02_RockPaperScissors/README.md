# じゃんけんゲーム

## 学習ポイント
Random、条件分岐、メソッド分割

## 概要
プレイヤー(標準入力)とコンピュータ(`Random`)でじゃんけんを行う対話式CLIアプリ。
「グー」「チョキ」「パー」のいずれかを入力すると、コンピュータの手と勝敗を表示する。`exit`で終了する。

## 実装メモ
- `Hand`(enum)に`beats(Hand other)`を持たせ、三すくみの勝敗ロジックをenum自身に閉じ込めた。
- 勝敗判定(`RockPaperScissorsGame.judge`)と乱数による手の抽選(`randomHand`)を分離し、それぞれ単体テストできるようにした。
- `randomHand`は`Random`を引数で受け取る設計にし、テストでは`nextInt`が固定値を返す匿名サブクラスを注入することで、乱数に依存せず決定的に検証した。
- `Main`は01_Calculatorと同じ設計パターンで、コンピュータの手を`Supplier<Hand>`として注入可能にし、`Main.run`の結合テストで勝敗表示や不正入力時の継続動作を確認できるようにした。
