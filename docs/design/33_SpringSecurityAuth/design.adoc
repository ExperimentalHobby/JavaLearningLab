== 概要

=== 目的
Spring SecurityとJWTによるステートレス認証、保護リソースの認可、ログイン試行制限を学習する。

=== 構成
`AuthController`が認証を受け付け、`JwtService`がトークンを発行する。`JwtAuthenticationFilter`がBearerトークンを検証し、`SecurityConfig`が公開・保護範囲を定義する。`LoginAttemptService`は連続失敗を一時的にロックする。

=== 関連資料
https://github.com/ExperimentalHobby/JavaLearningLab/issues/167[Issue #167]

== ユースケース

* UC-1: 認証情報からJWTを発行する
* UC-2: JWT付きで保護エンドポイントへアクセスする
* UC-3: トークンなし・期限切れアクセスを401で拒否する
* UC-4: ログイン失敗回数に応じて一時ロックする
