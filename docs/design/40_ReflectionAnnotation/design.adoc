== 概要

=== 目的
カスタムアノテーションとリフレクションAPIを使い、簡易的なフィールド検証ライブラリを実装する。

=== 構成
`@NotBlank`、`@Min`、`@Max`が制約を表し、`Validator`が実行時アノテーションを読み取って検証する。違反は`ValidationViolation`、アノテーションの型誤用は`AnnotationMisuseException`で表現する。

=== 関連資料
https://github.com/ExperimentalHobby/JavaLearningLab/issues/172[Issue #172]

== ユースケース

* UC-1: 検証対象のフィールドを走査する
* UC-2: アノテーションの制約違反を収集する
* UC-3: 継承元のフィールドも検証する
* UC-4: 型に合わないアノテーションの誤用を検出する

== 補足事項

アノテーションは`RetentionPolicy.RUNTIME`で保持する。合成フィールドを除外し、`getDeclaredFields`と親クラス走査で検証対象を決定する。
