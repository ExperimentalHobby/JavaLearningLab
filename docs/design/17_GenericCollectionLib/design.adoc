== 概要

=== 目的
任意の型を格納できる汎用スタック(`GenericStack<T>`)・キュー(`GenericQueue<T>`)と、境界型パラメータを使った汎用ユーティリティ(`CollectionUtils.max`)を提供するライブラリを、対話式CLI(`Main`)でデモする。Generic型と型安全なコレクション設計の実践を目的とする。

=== 主な機能
* `stack push/pop/peek/size <値>` でスタックを操作する
* `queue enqueue/dequeue/peek/size <値>` でキューを操作する
* `exit` によるアプリ終了

|===

`GenericStack<T>`/`GenericQueue<T>` はいずれも `Node<T>`(ネストしたジェネリッククラス)による単方向連結リストで自前実装されている。空コレクションへの操作は `EmptyCollectionException` をスローする。`CollectionUtils.max` は境界型パラメータ `<T extends Comparable<T>>` により、比較可能な任意の型に型安全に対応する。

== 補足事項

=== 連結リストによる自前実装
`java.util.Stack`/`Queue` をラップせず、単方向連結リストで自前実装している。`GenericStack` は `top` のみを持つ単純な連結リスト、`GenericQueue` は `head`/`tail` の両端を管理する連結リストとして設計し、どちらも `private static class Node<T>` をネストしたジェネリッククラスとして定義している。

=== 空コレクションのエラー統一
空のスタック/キューへの `pop`/`peek`/`dequeue` は、既存exerciseの「カスタム例外で統一する」方針に沿って `EmptyCollectionException`(非チェック例外)に統一している。

=== 境界型パラメータの活用
`CollectionUtils.max` は境界型パラメータ `<T extends Comparable<T>>` を使い、`Integer`・`String` など `Comparable` を実装する任意の型に対して型安全に動作することをテストで確認している。空リストは `IllegalArgumentException` とした。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。外部リソース(ネットワーク・ファイル・DB)に依存しない純粋なユニットテストのみで構成している(既存Issue #1〜#12と同様の方針)。

* *単体テスト*(`GenericStackTest`/`GenericQueueTest`/`CollectionUtilsTest`): push/pop/peek/size、enqueue/dequeue/peek/size、空コレクション時の例外、`max` の型安全な動作を検証
* *結合テスト*(`MainTest`): `stack`/`queue`コマンドの結果表示、および空コレクションへの操作・不正なコマンド入力時にエラー表示してループを継続する動作を検証

=== 設計上の工夫
* `Main` は01〜16と同じ設計パターンで、`Scanner`/`PrintStream` を引数に取る `run` 静的メソッドに分離している。
