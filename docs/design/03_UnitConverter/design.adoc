== 概要

=== 目的
数値と単位を入力すると変換する対話式CLIツールを提供する。長さ(m, km, cm, mm)と重さ(g, kg, mg)の2カテゴリに対応する。

=== 主な機能
* `"数値 変換元単位 変換先単位"` 形式の1行入力を解析して単位変換する(例: `5 km m`)
* 不明な単位、異なるカテゴリ間の変換(例: kmをgに変換)をエラー表示し、アプリを継続する
* `exit` によるアプリ終了

== 補足事項

=== カテゴリ管理の設計
各カテゴリの「単位→基準単位への換算係数」を `Map<String, Double>` で管理し(長さ→メートル、重さ→グラム)、`convert` は `value * fromFactor / toFactor` で計算する。複数カテゴリを `List<Map<String, Double>>` にまとめ、`fromUnit` がどのカテゴリに属するかを Stream API で検索する設計にしている。これにより新しいカテゴリ(例: 温度)を追加する際もリストに1つ追加するだけで済む。

=== カテゴリ不一致の防止
`toUnit` が `fromUnit` と異なるカテゴリの場合は `UnitConverterException` をスローし、意味のない変換(例: kmをgに変換)を防いでいる。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。

* *単体テスト*(`UnitConverterTest`): 長さ・重さそれぞれの変換、不明な単位、カテゴリ不一致を検証
* *結合テスト*(`MainTest`): `Scanner`/`PrintStream` を注入した対話ループに対して、不正入力時にクラッシュせず継続すること、正しい変換結果が表示されることを検証

=== 設計上の工夫
* `Main` は01_Calculatorと同じ設計パターンで、`Scanner`/`PrintStream` を引数に取る `run` 静的メソッドに分離し、結合テストを可能にしている。
