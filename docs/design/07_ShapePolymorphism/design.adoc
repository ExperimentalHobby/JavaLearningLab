== 概要

=== 目的
円・長方形・三角形の面積/周囲長を計算する対話式CLIツールを提供する。継承・抽象クラス・インタフェースを用いたポリモーフィズムの練習を目的とする。

=== 主な機能
* `circle <半径>` で円を登録する
* `rectangle <幅> <高さ>` で長方形を登録する
* `triangle <a> <b> <c>` で三角形を登録する
* `list` で登録済み図形と合計面積を表示する
* `exit` によるアプリ終了

== 補足事項

=== interfaceとabstract classの役割分担
`Measurable`(interface)で「面積・周囲長を計算できる」という契約を定義し、`Shape`(abstract class)がそれを実装した上で、図形共通の `describe()` メソッド(名前・面積・周囲長を組み合わせた説明文字列生成)を提供する構成にしている。interfaceは契約の定義、abstract classは共通実装の共有、という役割の違いを意識した設計。

=== ヘロンの公式と三角不等式
`Triangle` はヘロンの公式(`s=(a+b+c)/2`, `面積=√(s(s-a)(s-b)(s-c))`)で面積を計算する。コンストラクタで三角不等式(2辺の和が残り1辺より大きい)を検証し、成立しない場合は `ShapeException` をスローする。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。

* *単体テスト*(`ShapeTest`): 各図形の面積・周囲長計算、不正な寸法(負の半径・三角不等式違反)、`List<Shape>` として扱った際のポリモーフィズム(`shape.area()` が実行時の実際の型に応じて解決されること)を検証
* *結合テスト*(`MainTest`): `Scanner`/`PrintStream` を注入した対話ループに対して、不正入力時にクラッシュせず継続すること、複数図形登録後の合計面積表示を検証

=== 設計上の工夫
* `Main` は01〜06と同じ設計パターンで、`Scanner`/`PrintStream` を引数に取る `run` 静的メソッドに分離している。
