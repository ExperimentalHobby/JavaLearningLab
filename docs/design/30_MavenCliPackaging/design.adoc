== 概要

=== 目的
テキストファイルの行数・単語数・文字数を数える`wc`相当のCLIツールを提供する。これまでの29個は全て`Scanner`によるREPL形式だったが、本課題は最終回として「OSシェルから直接実行する実行可能fat jar」という配布形態そのものを学習対象にする(pom.xml管理・JARビルド・依存関係管理)。

=== 主な機能
* 引数で指定したテキストファイルの行数・単語数・文字数を表示する(既定はtext形式)
* `--format json` によるJSON形式での出力
* `--version` によるバージョン表示
* `--help` によるヘルプ表示(picocliの`mixinStandardHelpOptions`で自動提供)

=== 開発環境
[cols="1,3", options="header"]
|===
| 項目 | 内容

| 言語
| Java 25

| ビルドツール
| Maven(フォルダ単位で独立した `pom.xml`)、`maven-shade-plugin` 3.6.2による実行可能fat jarビルド

| テスト
| JUnit 5(`junit-jupiter` 5.11.3)

| 引数解析
| picocli(`info.picocli:picocli` 4.7.7、`@Command`/`@Parameters`/`@Option`による宣言的な定義)
|===

=== 実行方法
[source,powershell]
----
cd 30_MavenCliPackaging
.\mvnw.cmd clean package
java -jar target/mavenclipackaging-1.0-SNAPSHOT.jar <ファイルパス>
java -jar target/mavenclipackaging-1.0-SNAPSHOT.jar --format json <ファイルパス>
java -jar target/mavenclipackaging-1.0-SNAPSHOT.jar --version
----

== 補足事項

=== 依存関係管理(picocli)
引数解析に`info.picocli:picocli`を採用した。REPL系の課題では標準入力を`Scanner`で自前パースしていたが、picocliの`@Command`/`@Parameters`/`@Option`アノテーションによる宣言的な定義と比較できるようにした。

=== JARビルド(maven-shade-plugin)
`maven-shade-plugin`を`package`フェーズにバインドし、picocli本体を含む実行可能fat jar(`java -jar`単体で動く成果物)を生成する設定にした。`ManifestResourceTransformer`で`Main-Class`をマニフェストに書き込んでいる。

=== pom.xml管理(resource filtering)
`src/main/resources/app.properties`に`version=${project.version}`と記述し、`<resources><resource><filtering>true</filtering>...`でMavenのresource filteringを有効化した。ビルド時にpom.xmlの`<version>`(1.0-SNAPSHOT)へ実際に置換されることを、テスト(`--version`実行結果の検証)とビルド成果物の手動実行の両方で確認した。

=== テストでの出力キャプチャ
picocliのコマンドは標準出力へ直接書くのではなく、`@Spec CommandSpec spec`経由で`spec.commandLine().getOut()`/`getErr()`に出力する設計にした。これによりテストから`CommandLine#setOut(PrintWriter)`で出力を差し替え、モックなしで実際の出力内容を検証できる。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。全テストはpicocliの`CommandLine`を実際に実行し、`@TempDir`で作成した実ファイルに対して行っている。モックは使用していない。

* *単体テスト*(`TextStatisticsCalculatorTest`): 行数・単語数・文字数の計算(空文字・複数行・空白区切り)を検証
* *結合テスト*(`TextStatsCommandTest`): text/json形式での出力内容、存在しないファイル指定時の終了コード、`--version`実行時にpom.xmlのバージョンが表示されることを検証
