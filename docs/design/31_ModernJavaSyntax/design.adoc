== 概要

=== 目的
record、sealed interface、パターンマッチング、text blockを使った注文状態管理CLIで、Java 25の型安全な表現を学習する。

=== 構成
`OrderState`が受付・発送・配達・キャンセルの状態を限定し、`OrderStateTransition`が遷移を判定する。`OrderReceiptFormatter`はレシートを整形し、`OrderStatePersistence`はJacksonで状態を保存・復元する。

=== 関連資料
https://github.com/ExperimentalHobby/JavaLearningLab/issues/165[Issue #165]

== ユースケース

* UC-1: 注文状態を正当な次の状態へ遷移する
* UC-2: 不正な状態遷移を拒否する
* UC-3: 注文をJSONへ保存し復元する
* UC-4: text blockでレシートを表示する
