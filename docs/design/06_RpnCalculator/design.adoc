== 概要

=== 目的
逆ポーランド記法(RPN)の数式(例: `3 4 +`)を評価する対話式CLI電卓を提供する。数値は `BigDecimal` で厳密に計算する。

=== 主な機能
* RPN形式の数式を1行入力し、`java.util.Stack` を用いて評価する
* 不正なトークン・オペランド不足・不正な式・ゼロ除算をエラー表示し、アプリを継続する
* `exit` によるアプリ終了

== 補足事項

=== Stackによる評価アルゴリズム
`java.util.Stack<BigDecimal>` にトークンを順次push/popすることでRPNを評価する。演算子が来たら直近2つの値をpopして計算し、結果を再度pushする(例: `"3 4 +"` → 3をpush → 4をpush → `"+"` で2つpopして7をpush)。

=== 3種類の妥当性検証
パーサーとしての妥当性検証は3種類ある: ①数値でも演算子でもないトークン、②演算子適用時のオペランド不足、③評価終了時にスタックへ複数(または0個)の値が残る不正な式。いずれも `RpnCalculatorException` にまとめ、`Main` 側で一律にエラー表示・継続できるようにしている。

=== BigDecimalによる厳密な計算
01_Calculatorと同様、`0.1+0.2` のような誤差を避けるため `double` ではなく `BigDecimal` を使用する。除算はスケール10・`RoundingMode.HALF_UP` で丸める。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。

* *単体テスト*: 四則演算の評価、不正なトークン、オペランド不足、不正な式、ゼロ除算を検証
* *結合テスト*(`MainTest`): `Scanner`/`PrintStream` を注入した対話ループに対して、不正な式でクラッシュせず継続することを検証

=== 設計上の工夫
* `Main` は01〜05と同じ設計パターンで、`Scanner`/`PrintStream` を引数に取る `run` 静的メソッドに分離している。
