== 概要

=== 目的
タスクを追加・完了・削除・一覧表示できる対話式CLI ToDoリストを提供する。ファイルへの保存・復元にも対応する。

=== 主な機能
* `add <説明>` でタスクを追加する
* `done <番号>` でタスクを完了にする
* `remove <番号>` でタスクを削除する
* `list` でタスク一覧を表示する
* `save` / `load` でタスクをファイル(`todo.txt`)に保存・復元する
* `exit` によるアプリ終了

=== 開発環境
[cols="1,3", options="header"]
|===
| 項目 | 内容

| 言語
| Java 25

| ビルドツール
| Maven(フォルダ単位で独立した `pom.xml`)

| テスト
| JUnit 5(`junit-jupiter`、ファイルI/Oは `@TempDir` を利用)

| タスク管理
| `java.util.ArrayList`

| ファイルI/O
| `java.io`(`BufferedWriter`/`BufferedReader`)
|===

== 補足事項

=== インデックス検証の共通化
`complete`/`remove` はインデックス検証(`validateIndex`)を共通化し、範囲外アクセスは `ToDoListException` として扱う。

=== ファイル形式とラウンドトリップ
ファイル保存は学習ポイント通り `java.nio.file` ではなく `java.io`(`BufferedWriter`+`FileWriter`、`BufferedReader`+`FileReader`)で実装した。1タスク1行、`"[x] 説明"`/`"[ ] 説明"` 形式にすることで、保存・読込のラウンドトリップをテストで検証できるようにしている。`Task.fromFileLine` は `"[x] "`/`"[ ] "` がどちらも4文字であることを利用し、共通のオフセットで説明部分を取り出している。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。

* *単体テスト*: `ToDoList` の追加・完了・削除・範囲外インデックス、`Task` のファイル形式変換(`toFileLine`/`fromFileLine`)のラウンドトリップを検証
* *結合テスト*(`MainTest`): `Scanner`/`PrintStream` を注入した対話ループに対して、不正なコマンド・番号でクラッシュせず継続すること、`@TempDir` を用いた実ファイルI/Oを含めた `save`/`load` の一連の流れを検証

=== 設計上の工夫
* `Main` は01〜03と同じ設計パターンで、保存先ファイルも引数として注入可能にし、テストでは一時ディレクトリ(`@TempDir`)を使って実ファイルI/Oを含めて結合テストできるようにしている。
