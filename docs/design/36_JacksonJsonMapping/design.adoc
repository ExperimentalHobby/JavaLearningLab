== 概要

=== 目的
JacksonによるJSON/XML変換、日付処理、金額のカスタムシリアライズを実装する。

=== 構成
`ProductJsonMapper`と`ProductXmlMapper`が変換入口となり、`Product`をJSON/XMLへ変換する。`PriceSerializer`と`PriceDeserializer`が金額表現を制御し、`ProductList`がXMLのルート構造を表す。

=== 関連資料
https://github.com/ExperimentalHobby/JavaLearningLab/issues/168[Issue #168]

== ユースケース

* UC-1: 商品をJSONへ変換する
* UC-2: JSONから商品を復元する
* UC-3: 商品一覧をXMLへ変換・復元する
* UC-4: 不正な入力を変換エラーとして扱う

== 補足事項

LocalDateはモジュール設定で扱い、金額はカスタム変換で`150`と`150円`の表現を相互変換する。JSON/XMLのエラー形式は呼び出し側が識別できるよう統一する。
