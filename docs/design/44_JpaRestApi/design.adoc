== 概要

=== 目的
Spring Data JPAを使った商品CRUD、検索・ページング、在庫引き当てを実DBで扱うREST APIを実装する。

=== 構成
`ProductController`と`OrderController`がDTOを受け付け、`ProductService`がトランザクション境界を担う。`ProductRepository`が永続化し、`GlobalExceptionHandler`がエラーを統一する。OpenAPIとActuatorで運用情報を公開する。

=== 関連資料
https://github.com/ExperimentalHobby/JavaLearningLab/issues/176[Issue #176]

== ユースケース

* UC-1: 商品を登録・参照・更新・削除する
* UC-2: 商品を部分一致検索し、ページング・ソートする
* UC-3: 複数商品の在庫をトランザクション内で引き当てる
* UC-4: 在庫不足時にロールバックする
* UC-5: Swagger UIとActuatorでAPI・ヘルスを確認する

== 補足事項

在庫競合を防ぐため、注文処理では悲観ロックと`@Transactional`を使う。在庫不足や入力エラーはHTTPエラーへ変換し、TestcontainersではPostgreSQLとの結合を確認する。
