== 概要

=== 目的
Conwayのライフゲームを、`javax.swing.Timer` で世代更新しながらグリッドを描画するSwing GUIアプリを提供する。2D配列操作・GUI描画・タイマー駆動更新の実践を目的とする。

=== 主な機能
* マス目をクリックして初期パターンを編集する
* 「開始」でタイマーによる自動世代更新を開始する
* 「停止」で自動更新を止める
* 「1世代進める」で手動で1世代だけ進める
* 「クリア」で盤面を全消去する
* 「ランダム生成」でランダムな初期パターンを生成する

=== 開発環境

== 補足事項

=== テスト方針の分離
Issue #11/#18/#21と同じ方針で、`Grid`/`GameOfLife` はGUIに依存しない純粋なロジックとしてTDDし、`LifeFrame` は実装後に実機起動・スクリーンショットで手動確認した。

=== 盤面・世代カウンタの状態遷移の切り出し
当初「盤面のクリア」「ランダムな初期パターン生成」(UC-5・UC-6)が `LifeFrame` のボタンハンドラ・privateメソッドに直接実装されており、世代カウンタのリセットを伴う状態遷移がテストで検証できていなかった。

この状態遷移を `LifeBoardState` として切り出すことで、`Timer`/`JPanel`/`Graphics` に依存せずUC-1・UC-4・UC-5・UC-6をTDDで検証できるようにした。11_HouseholdBudgetGuiの `BudgetTableModel`、18_TextEditorSwingの `EditorDocument`、21_MazeSolverVisualizerの `MazeVisualizerState` 分離と同じ考え方を踏襲している。ランダム生成は `Random` をコンストラクタ注入することで、シード固定による再現性テストを可能にした(21の `MazeGenerator` と同じ考え方)。

UC-2(自動更新開始)・UC-3(自動更新停止)は `timer.start()`/`timer.stop()` という `javax.swing.Timer` への直接委譲のみで、抽出すべき独自ロジックが存在しないため、既存方針どおり手動確認のままとした(21のCanvas描画・アニメーションタイミングのような、切り出す余地のある計算処理を伴わないため、追跡用Issueも作成していない)。

=== 境界の扱い
`Grid` は `boolean[][]` の2次元配列で盤面を表現し、`countLiveNeighbors` は境界外を非生存として扱う(トーラス状のラップアラウンドはしない、盤面の端では隣接マスが少なくカウントされる仕様)。

=== 純粋関数としての世代更新
`GameOfLife.nextGeneration` は現在の `Grid` を書き換えず新しい `Grid` を返す純粋関数とした。世代更新中に元の盤面を参照しながら判定する必要があるため、インプレース更新だと参照している最中に値が変わってしまう不整合を避けられる。

=== 既知の周期パターンによる検証
ソルバーのテストでは、既知の周期パターン「ブリンカー」(3マスの直線が1世代ごとに90度回転する)を使い、隣接セル数だけでなく実際のパターン変化まで含めて `nextGeneration` の正しさを検証した。

=== タイマー駆動更新の実装
`LifeFrame` は `javax.swing.Timer` で一定間隔(150ms)ごとに世代を進める「タイマー駆動更新」を実装した。フレームワーク指定のない学習ポイントだったため、既存exercise(#11/#18)と同じSwingを採用し、新規依存関係を増やさずに済ませた。

=== 手動確認での検証内容
手動確認では、実際にWindows上でアプリを起動し、「ランダム生成」で初期パターンを作成→「開始」でタイマーが自動的に世代を進める(2秒間で13世代)ことをスクリーンショットで確認した。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。

* *単体テスト*(`GridTest`/`GameOfLifeTest`): 生存隣接数のカウント、境界外の非生存扱い、ブリンカーパターンでの世代遷移を検証
* *単体テスト*(`LifeBoardStateTest`): マスの生死反転、`step`による世代進行とブリンカーパターンの遷移、`clear`/`randomize`による盤面・世代カウンタのリセット、`randomize`の同一シードでの再現性を検証
* *手動確認*: `LifeFrame` のウィンドウ表示・マスクリック編集・開始/停止のタイマー動作を実機で確認
