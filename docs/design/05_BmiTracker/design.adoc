== 概要

=== 目的
身長・体重からBMIを計算し、判定結果とともに履歴をCSVファイルに保存・読込する対話式CLIツールを提供する。

=== 主な機能
* `add <身長cm> <体重kg>` でBMIを計算し測定記録として追加する
* `list` で測定履歴を表示する
* `save` / `load` で履歴をCSVファイル(`bmi.csv`)に保存・復元する
* `exit` によるアプリ終了

=== 開発環境
[cols="1,3", options="header"]
|===
| 項目 | 内容

| 言語
| Java 25

| ビルドツール
| Maven(フォルダ単位で独立した `pom.xml`)

| テスト
| JUnit 5(`junit-jupiter`、ファイルI/Oは `@TempDir` を利用)

| 履歴管理
| `java.util.ArrayList`

| ファイルI/O
| `java.io`(CSV、`BufferedWriter`/`BufferedReader`)
|===

=== 実行方法

----
cd 05_BmiTracker
.\mvnw.cmd compile
.\mvnw.cmd test
.\mvnw.cmd exec:java "-Dexec.mainClass=com.javalab.bmi.Main"
----

== 補足事項

=== BMI判定基準
`BmiCalculator` は日本肥満学会基準の4区分(低体重/普通体重/肥満(1度)/肥満(2度以上))で判定する。計算ロジックを `BmiHistory` から独立させ、単体で検証できるようにしている。

=== CSVファイル形式
学習ポイント通り、CSV読み書きは `java.nio.file` ではなく `java.io`(`BufferedWriter`+`FileWriter`、`BufferedReader`+`FileReader`)で実装している。1行目にヘッダ行(`date,height_cm,weight_kg,bmi,category`)を書き込み、読込時は最初の1行を読み飛ばす。`BmiRecord` に `toCsvLine()`/`fromCsvLine()` を持たせ、レコード1件の変換ロジックを `BmiHistory` のファイルI/Oから分離している。

=== テスト方針(TDD)
Red → Green → Refactor サイクルで実装した。

* *単体テスト*: `BmiCalculator` のBMI計算・4区分判定、`BmiRecord` のCSV変換のラウンドトリップを検証
* *結合テスト*(`MainTest`): `Scanner`/`PrintStream`/測定日 `Supplier<LocalDate>` を注入した対話ループに対して、`add`→`list`→`save` の一連の流れを決定的に検証

=== 設計上の工夫
* `Main` は測定日を `Supplier<LocalDate>` として注入可能にし(01〜04と同じ設計パターン)、テストでは固定日付を渡すことで結果を決定的に検証できるようにしている。
