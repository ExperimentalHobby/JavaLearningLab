# じゃんけん大会シミュレーター

## 学習ポイント
配列/コレクション、複数オブジェクトの管理

## 概要
複数プレイヤーのじゃんけんトーナメントを実施する対話式CLIツール。`register <名前...>`で参加者を
登録し、`start`でシングルエリミネーション方式の大会を実施して優勝者を表示する。`exit`で終了する。

## 実装メモ
- `Tournament`のコンストラクタで参加人数が2以上かつ2のべき乗であることを検証している。トーナメント表を組むには各ラウンドで人数がちょうど半分になる必要があるため。
- `playRound`は`List<Player>`を先頭から2件ずつインデックスでペアリングし、勝者だけを次ラウンド用の新しい`List`に集めていく。複数のPlayerオブジェクトをコレクションで管理しながら、ラウンドを重ねるごとに絞り込んでいく流れを1メソッドに凝縮した。
- あいこの場合は`handSupplier`(手を決定する関数)を再度呼び出して決着まで再戦する`while`ループを実装。本番では`Random`ベースなので毎回結果が変わり得るが、テストでは`Deque`から手を順番に取り出す関数を注入することで再戦ロジックを決定的に検証した。
- `runTournament`は`playRound`を参加者が1人になるまで繰り返すだけのシンプルな実装だが、02_RockPaperScissorsの1対1対戦ロジックを「複数人・複数ラウンド」に拡張した集大成という位置づけ。
- `Main`は01〜07と同じ設計パターンで、プレイヤーの手を`Function<Player, Hand>`として注入可能にし、`register`→`start`の一連の操作で優勝者が正しく表示されることを結合テストで検証した。
